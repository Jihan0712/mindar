# InRL

InRL ("In Real Life") is a mobile web app for making small 3D scenes and
attaching them to a personal marker: a QR code inside a piece of artwork.
Scan the marker and the scene appears on it in augmented reality. The same
scenes show in a social feed, in 3D or in AR.

The design source is the Figma file *INRL - FINAL (Copy)*: the **REVISED**
page holds the screens, the **DESIGN SYSTEM** page the colours, type and
components (see `src/styles/tokens.css`).

## How it is built

- **Web app**: React + TypeScript, built with Vite. Works in mobile Safari and Chrome.
- **3D**: three.js. One scene builder (`src/scene/buildScene.ts`) is used by every viewer, so a post looks the same everywhere.
- **Scene format**: `src/scene/schema.ts`. What InStudio will save and every viewer reads.
- **Marker tracking**: MindAR's image tracker (`src/ar/MarkerTracker.ts`), driven directly rather than through MindAR's three.js wrapper, which is outdated.
- **Hosting**: Cloudflare (Workers with static assets), live at https://inrl2.marine-469.workers.dev, deployed automatically from `main`.

## Commands

```bash
npm install
npm run dev        # local app at http://localhost:5173
npm test           # unit tests
npm run test:ar    # automated AR check with a fake camera (see scripts/ar-smoke-test.mjs)
npm run marker     # regenerate the test marker and its .mind tracking file
npm run build      # production build into dist/
```

Test media (video, music, photo) is generated by `scripts/make-test-media.py`;
third-party assets are listed in [CREDITS.md](CREDITS.md).
